Justflows

Set up your site

Justflows will install itself in the browser. You do not need a terminal.

The files are on the server, but the Node.js app is not running yet. In your host’s Node.js settings:

  1. Application startup file: server.js
  2. Click Restart App
  3. Refresh this page

Open install-token/TOKEN.txt in your site's folder — over FTP, or your host's File Manager — and paste the key below. It proves the setup is being run by whoever controls the files.
