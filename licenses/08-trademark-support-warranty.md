# 08 — Trademark, Support & Warranty Policy

**Applies to:** All users, developers, hosts, and contributors.

**Version:** 2.0

---

## 1. Trademark policy

### Protected marks

- **Justflows** (word mark)
- Justflows logo and official visual identity
- **Justflows Marketplace**, **Justflows Cloud**, **Justflows Payments**

### Permitted use

- *"Built for Justflows"*, *"Justflows plugin"* (factual compatibility)
- Accurate references and links to official sites

### Requires permission

- Logo use in marketing
- Product names implying official status (*"Justflows Pro Hosting by Acme"* without authorisation)
- Presenting a fork as official Justflows

### Fork naming

Forks must use a distinct name and state they are not official.

---

## 2. Support policy

| Supported | Not supported |
|---|---|
| Official MIT core releases | Modified core without reproduction on official builds |
| Unmodified self-hosted installs | Proprietary plugins/themes in official Marketplace channels |
| Justflows Cloud (if offered) | Custom core patches by third parties |
| Marketplace extensions (best effort) | |

Modified installations: no support guarantees. Security updates target official builds.

Enterprise SLAs may be offered under separate commercial agreement.

Report to: **security@justflows.com** *(replace)*

Advisories published for official releases. Fork maintainers responsible for merging patches.

## 5. Attribution requirements

When distributing Justflows Core or derivatives:

1. Preserve copyright notices
2. Include [MIT.txt](./MIT.txt)
3. Include [LICENSE](../LICENSE) and [LICENSING.md](../LICENSING.md)

When distributing plugins/themes, comply with the license declared in that package.
